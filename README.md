# SpendDNA – Your Wallet's Story

> Spotify Wrapped for your money.

SpendDNA is an industry-style transaction analytics project built using
Python, Pandas and NumPy.

The project analyzes six months of synthetic Indian UPI/bank transaction
data and extracts spending patterns, vendors, categories, anomalies and
financial personality archetypes.

## Features

### Mandatory Features

1. Transaction Parser
2. Vendor Extractor
3. Category Tagger
4. Spending Overview
5. Monthly Spending Trend
6. Time-of-Day Spending Patterns
7. Anomaly Detection
8. Spending Archetype Detection

### Bonus Features

- Day-of-week analysis
- Vendor cleanup audit
- Custom spending archetype
- Three-month spending forecast

## Technologies

- Python
- Pandas
- NumPy
- Google Colab
